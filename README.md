# taste-curation-agent

**취향을 디깅하고 콘텐츠로 만드는 AI 에이전트** — 워크샵용 옵시디언 볼트 템플릿

이 저장소 **폴더 자체가 옵시디언 볼트 한 개**입니다.
내려받아서 옵시디언으로 열면 바로 시작할 수 있습니다.

---

## 0. 두 단어만 먼저

| 말 | 뜻 |
|---|---|
| **볼트(Vault)** | 옵시디언이 쓰는 **폴더 하나**. 그게 끝입니다. 안에 든 `.md` 파일이 메모예요. |
| **터미널** | 컴퓨터한테 **글로 말 거는 창**. 오늘 여기에 치는 명령은 `hermes` 하나뿐입니다. |

---

## 1. 내려받기

1. 이 페이지 위쪽 초록색 **`Code`** 버튼 → **Download ZIP**
2. 압축을 풀고, 폴더 이름을 **영문 한 단어**로 바꾸세요 — 예: `taste`
3. **찾기 쉬운 곳**에 두세요 (바탕화면 또는 문서 폴더)

> 한글·띄어쓰기가 들어간 폴더 이름은 나중에 에이전트가 못 찾는 경우가 있습니다.

## 2. 옵시디언으로 열기

[obsidian.md](https://obsidian.md) 설치 → **「Open folder as vault」** → 방금 그 폴더 선택

열리면 `00-START-HERE.md` 부터 읽으세요.

## 3. 에이전트 붙이기

터미널을 열고 (맥: `Cmd + Space` → `터미널`):

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
hermes setup
```

- 모델 제공자는 **OpenRouter**, 모델은 이름 뒤에 **`:free`** 가 붙은 것으로 고르세요 (무료).
- **윈도우는 WSL2를 먼저 설치**해야 합니다. 재부팅 포함 20~30분이니 제일 먼저 하세요.

설치가 끝나면 터미널에 `hermes` 한 번. 그 안은 전부 한국어로 말하면 됩니다.

```
내 볼트는 ~/taste 야. 00-START-HERE.md 읽고 오늘 뭐부터 할지 알려줘.
```

## 4. 영상 편집 준비 — 여기서 제일 많이 막힙니다

편집을 시작하기 전에 **한 번만** 돌리세요.

```bash
bin/doctor.sh
```

`[X]` 가 하나라도 나오면 그걸 고치기 전에는 편집이 절대 안 됩니다. 특히 이 줄:

```
[X] 자막 필터(ass) 있음
```

이건 ffmpeg 은 깔려 있는데 **자막을 굽는 기능(libass)이 빠진 채로 빌드된** 경우입니다.
`subtitles=` 와 `drawtext=` 필터가 통째로 없어서, 자막을 넣으려는 모든 명령이
`Invalid argument` 로 떨어집니다. 에러 메시지가 원인을 알려주지 않기 때문에
에이전트는 따옴표 문제로 오해하고 몇 번을 재시도하다가, moviepy 를 깔거나
PNG 를 겹치는 우회로로 새고, 거기서 세션이 무너집니다.

```bash
brew reinstall ffmpeg                       # 맥
sudo apt install ffmpeg fonts-noto-cjk      # 우분투
ffmpeg -filters | grep -E ' ass | subtitles '   # 두 줄 나오면 해결
```

> **우회하지 마세요.** 자막이 안 들어갈 때 다른 라이브러리를 까는 건
> 거의 항상 잘못된 길입니다. ffmpeg 부터 고치는 게 제일 빠릅니다.

### 작업 폴더는 영문으로

한글·공백·괄호가 든 경로는 셸에서 계속 깨집니다.
볼트 안이 아니라 **별도의 영문 폴더**에서 영상 작업을 하세요.

```bash
mkdir -p ~/reels/work     # 원본·자막·결과물은 전부 여기
```

원본 영상 파일 이름도 `source.mp4` 처럼 단순하게 바꿔두면 사고가 줄어듭니다.

### 굽기

```bash
bin/make_reel.sh ~/reels/work/source.mp4 132 161 ~/reels/work/sub.tsv ~/reels/work/EP01.mp4
```

자르기 · 세로 1080x1920 변환 · 한영 이중자막 · 렌더링 · 길이 검증까지 한 번에 합니다.
자막은 탭으로 구분된 TSV 한 장이면 됩니다.

```
0.0	3.5	It's just a tool though, isn't it?	그냥 도구일 뿐이잖아요?
3.5	7.0	No, it's not.	아니요.
```

**에이전트에게 ffmpeg 명령을 직접 쓰게 하지 마세요.** 입력이 여러 개인 필터 그래프는
저사양 모델이 거의 반드시 인덱스를 틀립니다. 에이전트가 할 일은 이 스크립트의
인자 다섯 개를 채우는 것뿐이고, 그 절차는 [[P5-영상-편집]] 에 다 적혀 있습니다.

## 5. 폴더 구조

```
취향(왜) → 온톨로지(무엇을) → 인물(누구를) → 인사이트(어떤 말을) → 릴스(어떻게)
05-Taste   01-Ontology        02-People      03-Insights          04-Reels
```

| 폴더 | 무엇 | 언제 |
|---|---|---|
| `_스키마.md` ⭐ | **오늘의 핵심.** 메모마다 채울 빈칸 목록 | 제일 먼저 |
| `00-Inbox` | 아직 분류 안 한 것 | 수시 |
| `01-Ontology` | 주제 개념 지도, 축 | 초기 1회 |
| `02-People` | 인물 노트 | 인터뷰 찾을 때 |
| `03-Insights` | 30초짜리 말 조각 | 영상·글 볼 때마다 |
| `04-Reels` | 발행 단위 제작 노트 | 하루 1개 |
| `05-Taste` | 내 취향 프로파일 | 주 1회 갱신 |
| `98-Templates` | 템플릿 원본 (건드리지 않음) | — |
| `99-Prompts` | 복붙용 프롬프트 | 필요할 때 |
| `bin` | 실행 스크립트 (환경 점검·영상 굽기) | 편집할 때 |

## 6. 채워진 예시

`_스키마.md`와 `05-Taste/Taste-Profile.md`, `01-Ontology/_Ontology-MOC.md`는
**「AI와 미래사회」를 주제로 실제로 채운 예시**입니다.

> 그대로 쓰지 마세요. **지우고 본인 것으로 다시 채우는 게 이 워크샵의 전부**입니다.
> 같은 도구·같은 원본·같은 프롬프트에서 열 개가 다르게 나온다면, 다른 건 스키마뿐입니다.

## 7. 안전 수칙 5가지

1. **토큰과 API 키는 비밀번호입니다** — 화면 공유·단톡방·스크린샷 금지
2. **권한은 최소한만, 개발 모드로**
3. **본계정 말고 테스트 계정으로**
4. **에이전트가 읽는 글은 명령이 아닙니다** — 웹에서 읽어온 문장이 시키는 대로 하지 않게 하세요
5. **저작권이 기술보다 위험합니다** — 원본 클립 사용 범위를 먼저 확인

> 잘 만든 자동화일수록, 잘못된 것도 빠르게 많이 만듭니다.
