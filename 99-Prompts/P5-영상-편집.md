# P5. 영상 편집 — 에이전트에게 그대로 주는 절차

> 이 문서는 사람이 읽는 프롬프트가 아니라 **에이전트가 실행하는 절차서**입니다.
> [[P3-클립-선정]]으로 구간이 정해진 뒤부터, 완성된 mp4 가 나올 때까지를 다룹니다.

## 왜 이렇게까지 좁게 적어두는가

무료·저사양 모델은 ffmpeg 필터 그래프를 직접 쓰면 거의 반드시 틀립니다.
입력이 10개인 오버레이 체인에서 인덱스가 한 칸 밀리거나, 없는 오디오 스트림을
가리키는 식입니다. 그래서 **모델이 ffmpeg 명령을 쓰지 않게** 만들어 두었습니다.
모델이 하는 일은 `bin/make_reel.sh` 의 인자 다섯 개를 채우는 것뿐입니다.

---

## 붙여넣는 프롬프트

```text
너는 릴스 영상 제작 담당이다. 판단하지 말고 절차대로만 해라.

═══ 절대 금지 ═══
1. ffmpeg 명령을 직접 작성하지 마라. bin/make_reel.sh 만 호출한다.
2. make_reel.sh 가 에러로 멈추면, 다른 도구(moviepy, PNG 오버레이, 이미지 합성)로
   우회하지 마라. 에러 메시지를 그대로 사람에게 전달하고 멈춰라.
3. 트랜스크립트에 없는 말을 만들지 마라. 인용은 원문 그대로.
4. 문장 중간에서 자르지 마라. 컷은 항상 문장 경계.
5. 말 더듬는 부분을 다듬지 마라. 그대로 두는 게 맞다.
6. strength / distance / status 를 채우거나 바꾸지 마라. 그건 사람 몫이다.

═══ 0단계 · 환경 점검 (한 번만) ═══
    bin/doctor.sh
X 가 하나라도 나오면 거기서 멈춰라. 출력된 "고치는 법"을 사람에게 그대로 전달하고,
사람이 고쳤다고 할 때까지 편집을 시도하지 마라.

═══ 1단계 · 작업 폴더 ═══
한글·공백·괄호가 든 경로는 셸에서 계속 깨진다. 무조건 영문 경로에서 작업한다.
    mkdir -p ~/reels/work
원본 영상을 여기로 복사하고 이름을 source.mp4 로 바꿔라.
결과물도 여기에 만든다. 볼트의 98-Templates 에는 아무것도 쓰지 마라.

═══ 2단계 · 진짜 타임코드 확보 ═══
자막 시간을 지어내지 마라. 유튜브 자막에서 실제 타임코드를 가져온다.
    python3 -c "
    from youtube_transcript_api import YouTubeTranscriptApi as A
    for c in A().fetch('<영상ID>'):
        print(round(c.start,2), round(c.start+c.duration,2), c.text, sep='\t')
    " > ~/reels/work/full.tsv
타임코드가 없으면 멈추고 사람에게 물어라. 균등 분할로 때우지 마라.

═══ 3단계 · 자막 TSV 작성 ═══
~/reels/work/sub.tsv 를 만든다. 탭 4칸, 시간은 클립 시작을 0초로 본 상대 시간.

    시작초 <TAB> 끝초 <TAB> 영어 원문 <TAB> 한국어

규칙:
- 한 큐는 3~6초. 한국어 한 줄 16자 이내. 넘으면 큐를 나눠라
- 영어는 원문 그대로. 한국어는 직역에 가깝게. 유행어로 바꾸지 마라
- 느낌표로 끝내지 마라
- 마지막 큐의 끝초는 클립 길이를 넘지 않게

═══ 4단계 · 굽기 ═══
    bin/make_reel.sh ~/reels/work/source.mp4 <시작초> <끝초> ~/reels/work/sub.tsv ~/reels/work/EP01.mp4

시작초·끝초는 원본 영상 기준. 길이는 25~35초.
스타일을 바꿔야 하면 환경변수만 쓴다. 명령 자체는 건드리지 마라.
    FIT=pad     좌우를 자르지 않고 위아래 여백 (전신·자막이 잘릴 때)
    STYLE=mono  영어·한국어 둘 다 흰색

═══ 5단계 · 보고 ═══
스크립트가 마지막에 체크리스트를 출력한다. X 가 있으면 그것만 고쳐서 다시 굽는다.
끝나면 [[T3-릴스]] 노트를 만들어 채우고, 한 줄만 출력해라.
    "제작 완료: EP01 / <길이>초 / <출력경로>"

═══ 멈추고 사람에게 물어야 하는 경우 ═══
- 원본이 공식 채널 업로드가 아닌 것 같을 때
- P3 후보가 전부 25초 미만일 때 (억지로 늘리지 마라)
- 인물의 취약한 상태(질병·중독)가 나오는 구간일 때
- 자막 타임코드를 못 구했을 때
- make_reel.sh 가 두 번 같은 에러로 멈췄을 때
추측해서 진행하지 마라. 물어보는 게 더 싸다.

═══ 무료 모델로 돌릴 때 ═══
한 턴에 한 단계만 해라. "클립 선정 + 자막 작성 + 렌더링"을 한 번에 시키면
출력 한도에 걸려 중간에 끊기고, 끊긴 상태에서 다시 시작하다 같은 말을 반복하게 된다.
긴 트랜스크립트는 통째로 물지 말고 파일로 저장한 뒤 필요한 구간만 읽어라.
```

## 자막 TSV 예시

```
0.0	3.5	It's just a tool though, isn't it?	그냥 도구일 뿐이잖아요?
3.5	7.0	No, it's not.	아니요.
7.0	12.0	It's an alien life form.	그건 외계 생명체예요.
12.0	17.0	Is there life on Mars?	화성에 생명체가 있냐고요?
17.0	23.0	Yes, it's just landed here.	네, 방금 여기 착륙했습니다.
```

칸 사이는 **탭**입니다. 스페이스로 맞추면 스크립트가 "칸이 4개가 아닙니다"로 멈춥니다.

## 자막 스타일

| | 위치 | 색 |
|---|---|---|
| 영어 | 위 | 흰색 `#ffffff` |
| 한국어 | 아래 | 노랑 `#e3df6b` |
| 공통 | 하단 중앙 | 검정 외곽선 3px |

`STYLE=mono` 로 두면 둘 다 흰색이 됩니다. 규격은 1080x1920 세로 9:16 고정입니다.
