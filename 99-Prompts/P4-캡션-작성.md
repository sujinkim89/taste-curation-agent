# P4. 캡션 작성 프롬프트

````text
당신은 제 인스타그램 릴스 캡션을 씁니다. 카피라이터가 아니라, 이 클립을 친구한테 보내면서 한 줄 덧붙이는 사람처럼 쓰세요.

## 입력
- 클립 내용: [30초 발화 전문]
- 인물: [이름 / 왜 주목할 만한지 한 줄]
- 출처: [영상 제목 + 채널]
- 내 채널 톤: [Taste-Profile의 정체성 한 문장]

## 출력

### 1. 훅 문구 5개 (화면 상단 텍스트, 각 12자 이내)
서로 다른 유형으로:
- 반박형 ("~라고들 하지만")
- 질문형
- 고백형 ("나는 ~였다")
- 숫자형
- 장면형 (구체적 이미지)

### 2. 캡션 3안
각 안은 이 구조:
```
[1줄] 클립의 핵심을 다른 말로 (인용 반복 금지)
[2-3줄] 내 생각 또는 이걸 왜 골랐는지
[1줄] 열린 질문 또는 여운
출처: [영상 제목 — 채널명]
```
- 3안은 각각 톤이 달라야 합니다: 담백 / 개인적 / 도발적
- 총 300자 이내
- 이모지 최대 1개
- "여러분은 어떠신가요?" 같은 죽은 마무리 금지

### 3. 해시태그
- 핵심 3개 (주제 정확히)
- 확장 5개 (관련 커뮤니티)
- 브랜드 1개 (내 채널 고유 태그)
과도한 태그 나열 금지. 총 9개.

### 4. 첫 댓글 (고정용)
출처 링크 + 이 인물을 더 볼 수 있는 곳 1~2개.

## 톤 규칙
- 감탄사로 시작하지 마세요.
- "~인 것 같아요" 같은 흐린 어미를 남발하지 마세요.
- 클립이 이미 하는 말을 캡션이 반복하지 마세요. 캡션은 **각도를 하나 더** 주는 자리입니다.
- 인용문을 캡션에 통째로 다시 쓰지 마세요.
````
